- random.choice(items)
What it does: Picks a random element from a list or sequence.

Example:

```python
random.choice(['a', 'b', 'c'])  # could return 'b'
```
- random.randint(0, top_of_range)
What it does: Returns a random integer inclusive of both 0 and top_of_range.

Example:

```python
random.randint(0, 5)  # could return 0, 1, 2, 3, 4, or 5
```
- random.randrange(1, 11)
What it does: Returns a random number from a range, similar to range(1, 11) (i.e., 1 to 10), excluding the stop value (11).

Example:

```python
random.randrange(1, 11)  # could return 1 to 10 (not 11)
```
